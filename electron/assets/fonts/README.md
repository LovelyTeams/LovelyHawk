# Embedded fonts

The checked-in files are exact files from the pinned upstream release archives:

- Inter 4.1 `extras/ttf/Inter-Regular.ttf` and `Inter-SemiBold.ttf`
- Cascadia Code 2407.24 `ttf/CascadiaMono.ttf`

Their source URLs, SHA-256 digests, copyright notices, and full SIL OFL 1.1 text are recorded in `../../THIRD_PARTY_NOTICES.md`. Runtime font loading is entirely offline.

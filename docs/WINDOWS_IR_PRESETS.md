# Windows 文件、注册表与排查预设

2026-10-26。用户已确认两张 imagegen 草案，文件与注册表页面采用左侧导航、宽列表和下方详情。预览不再遮住列表；详情高度可拖动或键盘调整，关闭返回列表焦点，长路径与原始值可换行复制。注册表预设不再被选中值的详情替换。

- 文件：32 个目录预设，覆盖下载/临时目录、用户数据、启动目录、计划任务、PowerShell 配置、系统/驱动、事件日志/Prefetch/Amcache、IIS 和 SSH。使用目标环境变量；HKCU/用户目录对应采集账户。默认目录、OneDrive/已知文件夹重定向和缺失产品不构成已发现实例。
- 注册表：37 个预设，覆盖 Run/RunOnce/策略启动、IFEO/Winlogon/AppInit/AppCert/COM/文件关联、服务/驱动/任务缓存、LSA/WDigest/Defender/UAC、RDP/WinRM/代理/TCP、用户/USB/挂载痕迹。当前键筛选与预设搜索分开；访问拒绝和结果截断保持可见。
- 命令检查台：28 个固定只读查询预设，覆盖身份/权限、进程/网络、服务/内核及过滤驱动、任务、WMI 永久事件、审计/防护。选中只填入编辑器，仍走原有目标确认；不自动安装 WMIC。新版 Windows 优先使用 CIM，参考[微软 WMIC 移除说明](https://support.microsoft.com/en-us/servicing/os/windows/docs/2025/09/windows-management-instrumentation-command-line-wmic-removal-from-windows)。
- 文件“权限与占用排查”：按需读取属性、所有者、最多 64 条 ACL，以及相同路径的进程、服务、驱动和启动方式。CIM 每类最多检查 4096 项，最多显示 256 个进程和 128+128 个服务/驱动关联；失败、截断和权限不足明确提示。参数 Base64 传递，输出作为纯文本，目标变化使迟到结果失效。

诊断不枚举全部文件占用，不把 ACL 展示当作有效删除权限计算，不把路径一致当作加载/占用证明。受保护进程、TrustedInstaller、安全产品和内核驱动可能阻止处置；页面说明先留样、核对进程和启动项、维护窗口或可信恢复环境。没有自动夺取所有权、关闭防护、驱动卸载、文件强删或重启删除入口。已有删除仍需确认；驱动文件删除不等于驱动卸载。完整驱动签名/哈希/加载身份、受保护进程处置、内核信任核查及可恢复离线处置仍需后续设计与真实靶机验证。

UI 预设清单位于 `ui/src/renderer/win-ir-presets.ts` 和 `win-ir-command-presets.ts`；文件诊断沿 core `file_access.ps1` → backend → shared DTO → 原有宿主固定白名单 → 页面接线。未引入在线资源或第二套 UI。预设导航和命令清单不代表已经采集或排除了相关威胁。

本机 Windows 11 10.0.26200 x64 / PowerShell 5.1 的实际只读文件诊断通过，目标是本次测试独占创建的文件（名称含引号、反引号与字面命令替换标记），读取后原文件保持不变。取得 4 条 ACL，未取得同路径进程/服务；这不替代真实恶意程序或内核驱动样本验证。记录：`target/windows-redesign-4233e2fe-0252-49e1-bf01-caaa46ff1dec/file-access-readonly.json`。
